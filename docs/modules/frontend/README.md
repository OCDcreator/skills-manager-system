# Frontend Module Docs

Frontend source modules under `src/` map here one-to-one.

## Mapping

- `src/App.tsx` -> `docs/modules/frontend/App.md`
- `src/components/Foo.tsx` -> `docs/modules/frontend/components/Foo.md`
- `src/lib/domain/file.ts` -> `docs/modules/frontend/lib/domain/file.md`
- `src/views/FooView.tsx` -> `docs/modules/frontend/views/FooView.md`

Keep this README in sync when frontend source roots or high-level boundaries change.
